# TokiPlayer 🎵

یک TikTok جیسا audio/video player جو Android پر React Native سے بنایا گیا ہے۔

## خصوصیات ✨

✅ **Vertical Swipe Navigation** - اپر/نیچے swipe کر کے media navigate کریں
✅ **Audio & Video Support** - Audio اور Video دونوں چلائیں
✅ **Long Press Categories** - لمبا دبا کر category میں شامل کریں
✅ **Local Storage** - تمام ڈیٹا device میں محفوظ رہے
✅ **Categories System** - custom categories بنائیں
✅ **Progress Tracking** - Progress bar اور time display

## Tech Stack

- React Native 0.72
- TypeScript
- Zustand (State Management)
- react-native-video
- react-native-gesture-handler

## Installation & Setup

```bash
git clone https://github.com/wazykhan/TokiPlayer.git
cd TokiPlayer
npm install
```

## چلانے کے لیے

```bash
npm run android
```

## APK بنائیں

```bash
npm run build-apk-debug
```
